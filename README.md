# Pharma Sentinel

Учебное Streamlit-приложение для интерактивного изучения записей о лекарственных взаимодействиях из DDInter и честной проверки моделей предсказания связей.

> **Важно.** Это учебный прототип. Он не заменяет врача или фармацевта. Не меняйте лечение самостоятельно. Предсказание модели — гипотеза о структуре базы, а не доказанное взаимодействие или побочный эффект.

## Возможности

- Проверка пары препаратов по DDInter, подсказки при опечатках и осторожный текст для отсутствующей записи.
- Интерактивная карта выбранного препарата с фильтрами по уровням и ограничением числа связей.
- Топ-10 препаратов по числу связей `Major`.
- Топ-20 новых гипотез: сначала выбираются кандидаты с высоким Adamic-Adar, затем они ранжируются моделью. Уже известные в DDInter пары исключаются.
- Сравнение случайного леса, логистической регрессии, общих соседей, степени и случайного baseline по скрытым связям.
- Необязательный помощник на локальной языковой модели через Ollama: отвечает по выбранной строке DDInter, без облачного API и ключей.
- Интерфейс с переходами-анимациями и научными фотографиями Unsplash (для фото нужен интернет).

### Локальный ИИ без платных API

Экран **«ИИ-помощник»** работает с Ollama, установленной на компьютере. В терминале после установки Ollama выполните:

```bash
ollama pull qwen2.5:3b
```

Модель занимает около 1,9 ГБ по каталогу Ollama; локальная генерация не требует платного API-ключа. После загрузки она появляется в списке внутри приложения. Само приложение отправляет запрос на `localhost`; если Ollama не установлена или выключена, другие страницы остаются доступны. Используйте только локальные модели, не помеченные как cloud.

Языковая модель не ищет новые взаимодействия: она формулирует пояснение для конкретного факта DDInter, переданного приложением, и должна сообщать о границах этих данных. Графовая ML-модель решает другую задачу — ранжирует отсутствующие рёбра в сети. Ни один компонент не устанавливает клинический эффект, не оценивает риск для пациента и не назначает лечение.

Модель `qwen2.5:3b` и доступные размеры указаны в [каталоге Ollama](https://ollama.com/library/qwen2.5). Лицензия модели: Qwen License; проверьте её условия перед распространением или коммерческим использованием.

## Данные и очистка

Приложение читает восемь файлов `data/ddinter_downloads_code_*.csv` с колонками `DDInterID_A`, `Drug_A`, `DDInterID_B`, `Drug_B`, `Level`. Названия препаратов приводятся к нижнему регистру; пары сортируются по алфавиту; пары вида A=A удаляются; дубликаты сворачиваются до наиболее тяжёлого уровня: `Unknown=0`, `Minor=1`, `Moderate=2`, `Major=3`.

Ожидаемые контрольные числа после очистки: 1 939 препаратов, 160 235 уникальных пар; `Major` — 26 914, `Moderate` — 96 675, `Minor` — 6 833, `Unknown` — 29 813. Приложение вычисляет числа из файлов, а не подставляет контрольные значения.

Если CSV отсутствуют, загрузите исходные файлы с [ddinter.scbdd.com](https://ddinter.scbdd.com/) в разделе **Download** и положите все восемь CSV в `data/`. Приложение не создаёт демонстрационные или случайные строки базы.

## Проверка модели без утечки

Все связи случайно перемешиваются с `random_state=42`: 12% служат положительными обучающими метками, 20% — положительными тестовыми метками, оставшиеся 68% образуют граф для расчёта признаков. Ни train-, ни test-пары не добавляются в этот граф. Для каждой части выбирается равное количество отрицательных пар без записи во всей DDInter; обучающие и тестовые негативы выбираются без повторов.

Для пары рассчитываются шесть признаков только по графу: число общих соседей, коэффициент Жаккара, Adamic-Adar, степени обоих узлов и произведение степеней. Обучаются логистическая регрессия со `StandardScaler` и случайный лес (`n_estimators=200`, `min_samples_leaf=5`). Метрики: ROC-AUC, Precision@5000 и матрица ошибок леса при пороге 0.5. Для сравнения используются только общие соседи, только произведение степеней и случайное ранжирование.

Положительная тестовая метка означает, что пара была скрыта из графа, но записана в DDInter. Отрицательная метка означает случайную пару, которой нет в DDInter. Это не клинические категории «опасно» и «безопасно».

## Ограничения

- DDInter может быть неполной базой; данных по БАДам мало.
- Отсутствие пары в базе не подтверждает безопасность сочетания.
- Тестовые ложные срабатывания могут оказаться реальными, но не описанными взаимодействиями.
- Модель восстанавливает структуру связей в базе, а не клинический эффект для пациента.
- У 29 813 пар после очистки уровень `Unknown`.
- Результаты не заменяют консультацию врача или фармацевта.

Источник: Xiong G. et al., DDInter, *Nucleic Acids Research*.

## Запуск с нуля

Для запуска нужны Python 3.10+ и восемь исходных CSV в `data/`. Выполните пять команд из папки проекта:

```bash
cd /путь/к/pharma_sentinel
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

В Windows замените активацию окружения на `.venv\\Scripts\\activate`.

### Если возникла ошибка

- **Не найдены CSV:** скачайте файлы DDInter из раздела Download и проверьте имя каталога `data/` и шаблон имён `ddinter_downloads_code_*.csv`.
- **Нет колонки или неизвестный уровень:** проверьте, что это исходные CSV DDInter с ожидаемыми пятью колонками и значениями `Major`, `Moderate`, `Minor`, `Unknown`.
- **`streamlit: command not found`:** активируйте `.venv` и выполните `python -m pip install -r requirements.txt`, затем `python -m streamlit run app.py`.
- **Карта не отображается:** проверьте установку `pyvis` командой `python -m pip install -r requirements.txt`, затем обновите страницу.
- **Первый запуск модели медленный:** дождитесь расчёта; Streamlit кэширует загрузку и обучение для следующих переходов по страницам.
